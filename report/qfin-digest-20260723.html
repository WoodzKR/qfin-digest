Getting the Target Right in Return Prediction

수익률 대신 순위를 예측하면 성과가 크게 좋아진다

Training models on stock ranks beats training on raw returns.

Cyril Dujava

  • 머신러닝 연구는 모델 구조에만 매달려 왔다
  • 학습 목표를 원시 수익률에서 순위로 바꿨다
  • 대형주에서 수익률과 샤프지수가 약 두 배로 늘었다
방법
동일한 예측 모델을 두고 학습 목표만 원시 수익률과 횡단면 순위로 나눠 비교한다.
데이터
Cakici와 Zaremba가 주식 시장 자료로 검증했지만, 초록은 표본 기간과 시장을 밝히지 않는다.
시사점
기존 수익률 예측 모형의 라벨을 횡단면 순위로 바꿔 재학습하고 성과 차이를 직접 확인한다.
적용도 3/5
가격 자료만 있으면 순위 라벨을 바로 만들 수 있어 데이터 확보는 쉽지만, 모델과 매매 규칙은 직접 설계해야 해 3점이다.
  • ML research chases architectures, not the prediction target
  • Cakici and Zaremba swap raw returns for cross-sectional ranks
  • Large-cap returns and Sharpe ratios roughly double
Method
Hold the model fixed and vary only the training label: raw return level versus cross-sectional rank.
Data
Equity universes including large caps; the abstract names no sample period or market.
Use
Relabel an existing return-prediction model with cross-sectional ranks and measure the portfolio gap.
Score 3/5
Rank labels come free from price data, but you still build the model, universe and rebalancing rules yourself — hence 3.

ORIGINAL ABSTRACTRecent interesting research from Cakici and Zaremba, highlights an often-overlooked aspect of machine learning for equity return prediction: the choice of prediction target. Rather than focusing on increasingly sophisticated model architectures or feature engineering, the authors show that how returns are represented during training has a much larger impact on predictive performance. In particular, models trained to predict stock ranks instead of raw return levels generate substantially stronger portfolio performance—roughly doubling both returns and Sharpe ratios in large-cap universes.
